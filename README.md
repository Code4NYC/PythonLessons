# Python Lessons

Welcome to the Python Lessons repository! This repository contains lesson slides and corresponding code exercises for all four weeks of the Python workshop series.

## Lesson Slides
* **Week 1:** Introduction & Basics
* **Week 2:** Numbers, Conditionals, & Booleans
* **Week 3:** Loops & Repetition
* **Week 4:** Functions & Lists

## Code Files
* `Week1.py` - Exercises covering basic syntax and variables.
* `Week2.py` - Code implementing conditional logic and number operations.
* `Week3.py` - Scripts demonstrating `for` and `while` loops.
* `Week4.py` - Code practicing function definitions and list manipulation.
